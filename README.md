# Интернет-магазин по продаже цветов «Ромашка»
Сайт для заказа и быстрой доставки цветов по всему городу где также можно оставить отзыв о заказе


## Запуск сайта
Откройте терминал (командную строку) в папке с проектом.
Установите библиотеку Flask (выполняется один раз):
    pip install flask
Запустите сервер:
    python app.py
Откройте в браузере ссылку http://127.0.0.1:5000
